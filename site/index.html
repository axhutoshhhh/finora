Local-first personal finance for macOS.

Finora is an offline-first desktop application built with Python, Flask, SQLite, and WKWebView. It combines multi-account expense tracking, monthly budgeting, interactive reports, savings goals, and recurring payments without cloud accounts or telemetry.

Download v1.0.0 (Apple Silicon) View Source

Core Features

Ledger & Accounts

Integer-paise arithmetic, 5 account types, transfers, credit card repayments, split transactions, and linked refunds.

Budgets & Reports

Ten predefined categories, custom categories, monthly rollover, and locally bundled Chart.js analytics.

Goals & Recurring

Ledger-backed savings allocations, recurring rules with calendar anchor preservation, and subscription tracking.

Privacy & Backups

Loopback-only API, ephemeral launch token, strict CSP, SHA-256 ZIP backups, and an isolated demo workspace.

Architecture

Native macOS WKWebView (pywebview) → Loopback-only Waitress/Flask API → Authoritative Python Services → Parameterized SQLite Repositories. Local data is stored in ~/Library/Application Support/Finora/ with 0700/0600 permissions.

Verified Performance

On a 10,000-transaction synthetic dataset, Phase 4 indexing and frontend module optimization reduced median Overview UI loading from 230.68 ms to 82.41 ms (-64.3%), and 100,000-row Overview backend queries from 694.04 ms to 318.67 ms (-54.1%).

Download & Installation

Version 1.0.0 · Apple Silicon (arm64) · Tested on macOS 27.0.1. Packaged builds use local ad-hoc code signing (not Apple Developer ID notarized). You can also run directly from source with Python 3.13+.
